# 9. 픽셀 캐릭터 액션 루프

## 한 줄 인상

16비트 게임 스프라이트 같은 캐릭터가 기를 모아 한 방 쏘고 돌아오는 픽셀 아트 루프다.

## 유형·기본 규격

- 유형: 픽셀 캐릭터 루프
- 논리 해상도: 128×96. 화면에는 정수배로 확대한다.
- FPS: 갱신 60Hz 고정 스텝. 눈에는 8~12fps 도트 애니메이션으로 보인다.
- 길이: 약 11초(상태 한 바퀴)
- 루프: 한다. 이음매가 없다.
- 구현: 외부 자산·라이브러리·네트워크 없이 순수 JavaScript와 Canvas 2D의 단일 HTML

## 연출 방향

- 원작의 소재는 밤하늘 아래 주문을 시전하는 마법사다.
- 다듬어진 16비트 스프라이트 애니메이션처럼 보여야 한다. 벡터 도형을 줄여 놓은 것처럼 보이면 실패다.
- 배경은 최소로 한다: 어두운 하늘, 깜빡이는 1px 별 몇 개, 달, 돌바닥 선. 캐릭터의 실루엣이 또렷하게 읽혀야 한다.
- 팔레트는 약 24색으로 고정한다: 밤하늘의 깊은 파랑·보라, 따뜻한 옷 색, 밝은 마법 색 서너 개. 모든 픽셀이 이 팔레트에서 나온다.

## 장면 흐름

상태 기계가 한 바퀴 돌면 루프 한 번이다.

| 상태 | 화면 |
|---|---|
| 대기 | 2프레임 위아래 흔들림, 수염 흔들림 |
| 충전 | 지팡이를 들어 올린다. 보석이 깜빡이고 불꽃이 나선으로 빨려 든다 |
| 시전 | 밝은 폭발과 함께 발사체가 화면을 가로지른다. 화면이 1~2px 흔들린다 |
| 회복 | 자세가 가라앉아 대기로 돌아간다 |

## 기법

- 고정 논리 해상도의 오프스크린 캔버스에 전부 그린 뒤, 창에 들어가는 가장 큰 정수배로 확대해 가운데에 옮긴다. 이미지 스무딩을 끄고 CSS `image-rendering: pixelated`를 준다.
- 모든 그리기는 논리 캔버스의 정수 좌표에 스냅한다.
- 캐릭터는 채운 사각형과 픽셀 줄로 절차적으로 만든다(약 24×32 논리 픽셀). 원작은 굽은 뾰족 모자, 긴 수염, 두 톤 옷과 더 어두운 외곽선, 끝에 보석이 달린 지팡이로 구성한다.
- 포즈를 파라미터로 둔다(지팡이 각도, 팔 높이, 머리 기울기, 옷 흔들림). 키프레임 사이를 이징으로 부드럽게 보간하되, 매 프레임 픽셀 격자에 양자화해 도트 애니메이션의 뚝뚝 끊기는 맛을 낸다.
- 파티클은 미리 할당해 재사용하는 풀이다. 충전 때는 보석을 공전하고 시전 때 바깥으로 터진다. 수명에 따라 팔레트 인덱스가 흰색 → 마법 색 → 어두운 색으로 단계 이동한 뒤 사라진다. 그릴 때 위치를 격자에 스냅한다.
- 갱신은 60Hz 고정 timestep이고, 루프 안에서 객체를 새로 만들지 않는다.
- 보석에서 오는 1px 림 라이트가 캐릭터 가장자리에 걸리고 충전과 시전 때 밝아진다.

## 금지

서브픽셀 위치, 안티앨리어싱, 그라데이션, `shadowBlur`, 팔레트 밖의 색, 외부 자산.

## 주의

- 영상으로 낼 때는 rAF 루프를 [공통 규약](../conventions.md)의 고정 스텝 `seek(t)`로 바꾼다. 난수는 시드 고정으로 바꾼다.
- 정수배 확대가 캔버스에 딱 맞아야 한다. 128×96은 1920×1080에 정수배로 맞지 않는다. 캔버스를 1920×1440(15배)이나 1280×960(10배)으로 잡거나, 논리 해상도를 16:9(예: 160×90의 12배)로 바꾼다.
- `--subframes 1`로 렌더한다. 섞으면 픽셀이 흐려진다.
- 루프 끝에서 파티클이 모두 사라져 있어야 첫 프레임과 이어진다.

## 바꿀 것

- 캐릭터(마법사 → 사용자의 마스코트)
- 동작 상태
- 팔레트의 분위기
- 논리 해상도

## 지킬 것

- 정수 스냅 렌더링과 정수배 확대
- 파라미터로 둔 포즈와 격자 양자화
- 상태 기계
- 풀링 파티클
- 품질 기준: 어떤 크기에서도 선명한 픽셀, 이음매 없는 루프, 읽히는 실루엣

## 채울 것

- 영상 캔버스 크기와 정수 배율
- 결정적 재현: 공통 규약의 "실시간 루프로 쓰인 템플릿"

## 필요한 입력

- 캐릭터의 모습(형태, 색, 특징 두세 가지)
- 한 바퀴에 할 동작(예: 충전 후 발사, 점프, 변신)
- 배경과 팔레트 분위기(밤, 낮, 실내)
- 화면 비율
