# fullops 2.3.1

규칙·명령·lint 규칙을 남길지 지울지 데이터로 정하려고 사용량 기록을 더한 판이다. X-01 안내 문구를 고쳤고, 릴리스 PR이 머지되면 태그와 GitHub Release가 자동으로 생긴다.

## 달라진 것

- 사용량 기록: hook·CLI·`lint`가 호출마다 한 줄을 `<git-common-dir>/fullops/usage/<UTC 날짜>.jsonl`에 더한다. 활성 레포(`.fullops/fullops.toml`이 있는 레포)에서만 쓴다.
  - 남기는 것: hook은 이벤트, 호스트, 판정(`pass`·`context`·`warn`·`deny`·`block`), 평가한 규칙마다 `<ID>:<결과>`, 오류 종류. CLI는 명령 이름, 알려진 하위 명령 낱말(`new`·`check` 등), 종료 코드. `lint`는 finding 코드별 개수(`[A-Z]+-숫자` 꼴이 아닌 레포 코드는 `OTHER`), 레포 명령의 상태별 수, 통과 여부. 모든 줄에 시각(에폭 초)이 붙는다.
  - 남기지 않는 것(원문 없음): 명령 문자열, 경로, 프롬프트, 인자 값(과제 키 등), 판정 문구, 지문, 세션 ID, lint 메시지.
  - 상한: 하루 파일이 1MB를 넘으면 그날 남은 줄은 버린다. 새 날 파일을 만들 때 날 파일이 60개 이상이면 오래된 것부터 지운다(달력 60일이 아니라 날 파일 60개다. 쓰지 않은 날은 세지 않는다).
  - 공용 디렉터리라 리뷰 snapshot 정리, `gc`, 14일 세션 정리가 지우지 않는다.
  - 쓰기는 잠그지 않고 실패는 버린다. hook 판정과 명령의 종료 코드는 바뀌지 않는다.
  - 형식과 읽는 법은 설계 6.2.4절에 있다.
- `fullops doctor`: `사용량 기록` 줄이 생겼다. 날 파일 수와 처음·마지막 날(`3일(2026-11-20~2026-11-22) <경로>`), 아직 없으면 `아직 없음 <경로>`를 보인다. 경고는 내지 않는다.
- X-01 안내(이슈 #57): dev 직접 작업(BlockAlways)의 Stop 차단 문구 끝의 "(BlockOnce일 때만)" 탈출구가 다시 끝내면 통과하는 것처럼 읽혔다. 이제 "dev 직접 작업이면 다시 끝내도 통과하지 않는다: 하위 에이전트가 아직 쓰고 있으면 끝날 때까지 기다린 뒤 커밋한다. 그 밖에는 적용할 검사가 없으면 이유를 말하고 다시 끝낸다"로 나온다. 판정과 지문은 그대로다.
- 위임 기준 템플릿(`.fullops/guide/rules/delegation.md`): `on` 행에 "쓰기 하위 에이전트가 끝날 때까지 턴을 끝내지 않는다"를 더했다.
- 릴리스 워크플로: `release/v<버전>-<실행 번호>` PR이 main에 머지되면 머지 커밋에 태그 `v<버전>`과 GitHub Release(본문은 이 릴리스 노트)를 만든다. 전에는 사람이 손으로 만들었다. 이미 있으면 덮지 않고 실패한다.

## 적용

1. `npx --yes github:tourbut/fullops install`을 실행하고 플러그인을 다시 읽는다. 사용량 기록은 실행본에 들어 있으므로 플러그인만 갱신해서는 쌓이지 않는다. 고정 위치 실행본도 2.3.1이어야 한다. `install`이 함께 갱신하고, 플러그인만 갱신했다면 다음 hook 호출의 S-04 자동 설치가 갱신한다(`install.json`의 `pinned`가 참이면 하지 않는다). 직접 하려면 `fullops install --only runtime`.
2. lead 체크아웃에서 `fullops doctor`를 실행해 `사용량 기록` 줄을 본다. 몇 번 hook·CLI를 부른 뒤에도 `아직 없음`이면 같은 출력의 실행본 줄(고정 위치 실행본 버전)을 확인한다.
3. `delegation.md`는 `fullops init`을 다시 실행해도 덮어쓰지 않는다. 레포의 파일이 이전 템플릿 그대로면 이번 판의 템플릿 글로 바꾸고, 고친 파일이면 `on` 행의 한 문장만 옮겨 적는다. 필수 적용 검사는 더하지 않았다.
4. `fullops upgrade --verify`로 `applied_version`을 2.3.1로 올리고 커밋한다.
