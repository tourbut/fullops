# fullops 2.0.2

macOS 점검에서 나온 문제 셋을 고친 판이다.

## 달라진 것

- 날것 `orca orchestration worker-start`나 `dispatch`를 막을 때(T-01) 거부 문구가 두 명령을 함께 가리킨다. 2.0.1에서는 `dispatch`를 막을 때도 `worker-start`만 적어서, 모델이 hook이 명령을 잘못 읽었다고 보고했다. 막는 판정은 그대로다.
- `fullops doctor`는 grok의 `trusted_folders.toml`을 TOML로 읽지 못하면 파일 경로와 오류를 보여 주고 고치라고 안내한다. 2.0.1에서는 이 경우를 "신뢰 없음"으로만 보여 줬다. 같은 폴더가 두 번 적힌 파일(옛 Python 판이 남길 수 있다)이 이렇게 깨지며, 이때는 grok도 폴더 신뢰를 저장하지 못한다.
- `npx --yes github:tourbut/fullops version`(`--version`, `-V`도 받는다)이 받은 실행본의 버전을 낸다.

## 적용

1. `npx --yes github:tourbut/fullops install`을 실행한다.
2. `fullops doctor`에 grok 신뢰 파일 오류가 나오면, 그 파일에서 중복 항목을 지운다. 지우기 전에 파일을 따로 복사해 둔다.
